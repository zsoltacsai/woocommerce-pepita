## 3. Discrepancy & Gap Analysis Summary

### Identified Gaps:
1. **`<EmailDelivery>` Field:**  
   Documented in official spec (`true`, `false`, `1`, `0`). Indicates email-based delivery for digital goods. Previously unmapped in `Product_Mapper` and omitted in `Xml_Writer`.  
   *Fix:* Add mapping for `_wps_email_delivery` post meta or virtual/downloadable products; emit `<EmailDelivery>` when enabled.

2. **`<Author>` and `<Publisher>` Book Fields in `<Descriptions>`:**  
   Documented in official spec Table 1.  
   *Fix:* Map `_wps_author` and `_wps_publisher` post meta in `Product_Mapper` and output them under `<Descriptions>` in `Xml_Writer`.

3. **Variation Level `<Prices>` Elements (`<VatPercent>`, `<PurchaseNetPrice>`, `<ShippingPrice>`):**  
   `pepita-sample.xml` includes `<VatPercent>27</VatPercent>` under `<Variation>/<Prices>`, and Table 2 specifies optional `<PurchaseNetPrice>` and `<ShippingPrice>`. `Xml_Writer` previously wrote only `Currency`, `Price`, and `DiscountedPrice`.  
   *Fix:* Output `<VatPercent>`, `<PurchaseNetPrice>`, and `<ShippingPrice>` in `Xml_Writer::variations()` when present and full feed is generating.

4. **Variation Level `<RestockDate>` in `<Availability>`:**  
   Table 2 documents `<RestockDate>` under `<Variation>/<Availability>`, but `Xml_Writer::availability()` suppressed `RestockDate` when `$variation === true`.  
   *Fix:* Allow `<RestockDate>` on variations when specified.

5. **Single `<Categories>` Container Enforcement:**  
   The official spec defines `<Categories>` as a single container per product with hierarchical `<Category>` child elements (`Könyvek > Babanapló`). While `PEPITA-FEED-MAPPING.md` permitted repeated `<Categories>` tags for multiple assignments, Pepita's reference XML shows a single `<Categories>` element.  
   *Fix:* Ensure that primary category hierarchy is always output inside a clean `<Categories>` container, preventing malformed or empty category structures.
