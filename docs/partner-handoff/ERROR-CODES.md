# WP Pepita Sync — Operational Error Codes & Diagnostic Reference

This document catalogs all system diagnostic codes, error definitions, and resolution guidelines across WP Pepita Sync modules.

---

## 1. Feed Validation & Generation Errors

| Code | Severity | Description | Merchant Action |
|---|---|---|---|
| `missing_mandatory_field` | High | Product lacks mandatory Pepita fields (name, description, price, VAT rate, or currency). | Complete missing product data in WooCommerce. |
| `invalid_image_file` | High | Image attachment fails format checks (not JPG/PNG), dimension requirements (< 1200×630), or file is truncated/corrupted. | Upload compliant, high-resolution JPEG or PNG images. |
| `malformed_gtin` | Medium / High | EAN/GTIN fails length validation (must be 8, 12, 13, or 14 digits) or check digit calculation. | Correct GTIN in product settings or category rules. |
| `variable_missing_axes` | High | Variable product has incomplete attributes or duplicate variation combinations. | Re-generate variations or assign distinct attributes in WooCommerce. |
| `feed_shrinkage_detected` | Critical | Exportable catalog decreased by more than 20% compared to previous snapshot. Feed quarantined. | Review excluded products; approve staged feed in admin if change is intentional. |
| `margin_below_threshold` | Warning / Gate | Product sales price results in net profit margin below the configured threshold. | Review purchase costs (COGS) and pricing rules under "Készlet és árazás". |
| `lock_held` | Info | Another background worker is actively generating the XML feed. | Wait for existing generation to complete; stale locks (> 15 min) auto-reclaim. |

## 2. Order Ingestion & Webhook Errors

| Code | HTTP Code | Description | Technical Resolution |
|---|---|---|---|
| `unauthorized` | 401 | Missing or invalid API key in `Authorization` header. | Verify Order API key in Pepita Seller Portal matches plugin settings. |
| `bad_request` | 400 | Webhook body contains malformed JSON or unparseable syntax. | Inspect dispatcher logs for truncated HTTP payloads. |
| `validation_failed` | 422 | Required fields missing or invalid monetary format. | Ensure gross, net, VAT, and customer address structures conform to contract. |
| `unresolved_product` | 422 | Neither SKU nor Exporter Product ID matches an active WooCommerce product. | Synchronize product catalog before accepting live orders. |
| `currency_mismatch` | 422 | Order currency does not match store currency without multi-currency plugin. | Configure WooCommerce currency matching the Pepita marketplace country. |
| `conflict` | 409 | Duplicate Pepita Order ID received with conflicting item or price data. | Check order history; Pepita must issue unique order IDs for amendments. |
| `label_save_failed` | Logged (Non-blocking)| Package label PDF was corrupted or disk space was exhausted. | Check `wp-content/uploads/wps-pepita-labels/` permissions and disk quota. |

## 3. Merchant Profiles & Multi-Store Automation Errors

| Code | Stage | Description | Resolution |
|---|---|---|---|
| `unsupported_schema` | Upload / Preflight | Profile `schema_version` is missing, not integer, or does not equal `1`. | Use compatible profile export generated by WP Pepita Sync. |
| `checksum_mismatch` | Preflight | Calculated SHA-256 canonical checksum does not match profile `checksum`. | File has been corrupted or edited; re-export or regenerate checksum. |
| `sensitive_key_stripped` | Notice | Profile contains unallowlisted or secret keys (`feed_token`, `storage_key`). | Informational notice; plugin automatically strips secrets for safety. |
| `category_update_failed` | Import / Rollback | WordPress `update_term_meta` failed during category rules import. | Triggered compensating rollback; original settings and metadata restored. |
| `profile_import_recovered` | Admin Load | An interrupted import from a prior server crash was detected in recovery journal. | Informational warning; plugin restored clean baseline store state automatically. |
